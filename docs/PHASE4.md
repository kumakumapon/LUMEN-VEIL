# Phase 4 — 生きた世界と冒険
## 目標
本格タイルマップ（視覚タイルと衝突グリッド）、自律巡回NPC、依頼と報酬、ショップ、状況対応型敵AI、キャラクターの高精細表示を序章に追加する。

## 絶対に守ること
- 旧 `chapter-zero` / `chapter-zero-expansion` と version=1 のJSON/IndexedDB互換。
- Phase 4のクエスト・ショップ情報は同じIndexedDB `slots` の新キーに分離する。既存データの無断初期化や破壊をしない。
- `/LUMEN-VEIL/` ベースパス、`npm run build` とPagesデプロイを変更しない。
- 旧序章のフラグ・物語・既存エリア移動を保ち、PC・スマートフォンで通しプレイ可能にする。
- 第3フェーズのmain CIで発生したエリア遷移のE2E不安定性を解消する。

## 実装と受け入れ
1. グリッド地形（歩行可否、タイル描画、障害物、歩行経路）を定義し、マップ上で視覚化。旧ホットスポット操作を維持。
2. NPCの巡回、待機、会話中停止、設定の「演出を減らす」への対応。
3. 依頼の受注・達成・報酬受け取りと、クエスト帳。進行フラグとの整合。
4. 所持金・買い物・購入後の装備画面反映、二重購入防止と不足金チェック。
5. 戦闘の敵意図表示と防御・対象選択・HP状況を考慮したAI。旧戦闘を破壊しない。
6. キャラクター立ち絵/マップキャラの高精細化。失敗時フォールバック。
7. Nodeテスト、Vite型チェック、Playwright PC/モバイル通しプレイ、旧セーブ復元、Pagesパス検証。
