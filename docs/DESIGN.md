# LUMEN VEIL — 序章「消える港」実装設計

## 今回の完成範囲
新規開始から、浮遊港オルテの探索、セナ・リッツとの出会い、記憶灯の修復、保管庫、忘鐘戦、飛空艇での脱出まで完走できる序章の最初の実装。
プレイ時間30〜45分は企画上の目標。初版はゲームの核を検証できる短い構成とし、実測せずに時間を保証しない。

## 構造
- TypeScriptの独立した進行・戦闘・保存モデルを唯一の状態源にする。
- Phaserは背景、プレイヤー表示、目的地、敵味方、光と移動演出を描く。
- HTML/CSSはタイトル、会話、コマンド、ジャーナル、設定を描く。画像のUIは使わない。
- シナリオとエリア定義をデータに分離。港、回廊、保管庫、船着き場の4エリア。
- 移動は安全な通路をつないだ地点間の移動。クリック・タップ・矢印キーで地点を選び、Enterで調べる。自由歩行の当たり判定マップと歩行連番は次段階。

## 進行
港でセナの話を聞く→失われた看板を記憶灯で調べる→回廊でリッツを救出する戦闘→装置を修復→保管庫の鍵を取得→保管庫で忘鐘を倒す→船着き場で脱出。
寄り道は港の手紙と回廊の船員の名札。収集した記録はジャーナルとエンディングに反映する。
会話・移動後・戦闘結果で自動保存。会話途中・戦闘途中は安定した直前の探索状態から再開する。

## 戦闘
初期HPはノエル180、セナ145、リッツ210。行動ゲージは速度で進み、手番選択中は全体を停止。
敵の大技は前の手番から予告。弱点・崩し技で耐勢を0にすると一度遅延、破壊中に被ダメージ増加。
共鳴100を消費して直前の対応する味方行動を60%で再演。自分の手番を消費する。再演自体・アイテム・防御は記録しない。
同じ行動で再演後に共鳴が回復しない。回復対象と攻撃対象は必ず選択・検証する。全滅で敗北、直前から再挑戦可能。
通常戦闘を3種とボス1種用意。難易度を設定可能。

## 保存と操作
IndexedDB、形式version=1。読み込むデータを検証し、未知版・壊れたデータを拒否して既存セーブを保持。
手動保存、続きから、JSON書出し・読込み。保存失敗は画面に表示し、黙って成功扱いにしない。
設定は音量、演出軽減、文字サイズ、難易度。設定を変更しても進行は失わない。
タブ非表示、メニュー、会話中は戦闘時間を停止。音声はユーザー操作後に開始し、非表示時は休止する。

## アートと音
前回生成の世界観絵をタイトルに使用。探索背景、3人の人物素材、忘鐘の素材を別生成する。
群青・白金・青緑・琥珀。和文ゴシックの本文と明朝の見出し。画面中心をHUDで覆わない。
初期のBGMはWeb Audioの短いオリジナル主題を場面ごとに変奏する。録音・フルオーケストラ音源への差替えは後続。

## 検証・残項目
純粋モデルの戦闘・進行・セーブ検証をNodeテスト、ブラウザ操作をPlaywrightで実施。
開始からクリア、敗北と再戦、保存と再開、JSON異常系、キーボード・タッチ、モバイル表示を確認。
全6章、自由歩行マップ、歩行・攻撃連番、クラウド同期、装備の拡張は後続。序章でも戦闘中装備変更・回復アイテム購入は初期範囲外。
