# Phase 3 — フィールド・会話・敵AI・装備・育成・探索

## 非破壊の基本方針
- `web/model.mjs` の v1 セーブ形式・旧フラグ・パーティHP/MP検証と `web/save.mjs` の DB名、ストア、`chapter-zero` キーは維持。
- 新しい育成/装備は同じIndexedDBストアの **別キー** に保存し、旧セーブを読む場合は初期育成状態にフォールバック。新規データを保存しても旧キーを書き換えない。
- JSONの旧形式インポートはそのまま受理し、拡張セーブの輸出入は旧フォーマット互換を確保。
- GitHub Pagesの `/LUMEN-VEIL/`、Viteビルド、PR→main公開CIは変更しない。

## 機能
- 歩行領域と障害物、地点への経路探索・接近して調べる操作、NPC対話UI。
- 敵の行動予告・行動選択AI、弱点・BREAK・残響と連携。
- 経験値、レベル、武器/防具の装備、育成表示、戦闘への効果。
- 港から寄り道できる市場と観測塔、会話・アイテム収集、往復できる導線。

## 検証
- 旧v1セーブ/不正データ非破壊/新育成データの保存・復元・バリデーション。
- Node単体テスト、TypeScript型チェック、Vite Pagesビルド、Playwright PC/スマホ通しプレイ。
