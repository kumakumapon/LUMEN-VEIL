# LUMEN VEIL — ビジュアル設計

- 基調色: 夜の群青 `#071321`、白金、青緑 `#a6dfde`、琥珀 `#ebc994`。
- 背景と人物は高精細な幻想アニメ調、UIは実装可能なHTML/CSSで再構築する。ゲーム操作に必要な文字を画像へ焼き込まない。
- `web/assets/skyport.webp`: 生成した世界観キービジュアルをWebPへ圧縮。タイトル・港・船着き場の背景として使用。
- `web/assets/forgotten-bell.webp`: 生成した戦闘コンセプトから忘鐘の周辺を切り出し、保管庫の背景として使用。
- `docs/battle-concept.webp`: 生成した戦闘画面の方向性資料。ゲーム内HUDはHTMLで再現しており画像の文字をそのまま表示しない。
- `web/assets/skyport.svg`: 手描きの軽量プロトタイプ用背景。画像の読み込み失敗を検証するため残し、アート方向性の補助とする。

## 後続アセット

- ノエル/セナ/リッツ/ヴァルドの設定画・全身立ち絵・表情差分・歩行アニメーション。
- 忘鐘の敵スプライトと攻撃差分・術技エフェクト。
- 港・回廊・保管庫・船着き場ごとの独立した背景・昼夜差分。
- 画像のサイズ・重複・透明領域・モバイル読み込み容量を検証し、アセットごとのWebP/PNG適性を判断する。

すべて本企画向けに作成したオリジナルのコンセプト。既存ゲームのキャラクター・作品固有のUIや意匠を複製しない。
