# LUMEN VEIL — 名前のない夜明け

オリジナルのブラウザJRPG。**序章「消える港」**（浮遊港オルテ→整備回廊→保管庫→飛空艇）をPC・スマートフォンで遊べます。背景・立ち絵・街のアニメーションはオリジナルの生成画像／Phaser描画です。

**GitHub Pages:** https://kumakumapon.github.io/LUMEN-VEIL/

## 技術構成

- **Vite + TypeScript + Phaser 3**: マップ描画・歩行スプライト・移動・ホットスポット・戦闘エフェクト。
- **DOM/CSS UI**: 会話、ステータス、探索候補、コマンド、セーブ操作。Canvasが無効でも操作できる構成。
- **Web Audio API**: 画面ごとのオリジナルBGMとSEをシンセサイザーで生成。クリック/キー操作後のみ再生し、非表示タブでは停止。
- **既存のゲームモデル（`web/model.mjs`）と保存（`web/save.mjs`）を維持**: v1 IndexedDB・JSONセーブの互換性を優先。歩行位置、ATBゲージ、音声の再生時刻はセーブに追加しません。
- **GitHub Actions**: テスト→Pagesパス検証→Playwright E2E→`main` からPagesに公開。

## 開発

Node.js 22.12以降を推奨。

```bash
npm ci
npm run dev
# http://127.0.0.1:4173/LUMEN-VEIL/
npm test
npm run typecheck
npm run build
npm run preview
```

## 操作

| 場面 | PC | スマートフォン |
|---|---|---|
| 探索 | WASD/矢印キーで歩く、地点をクリック・選択肢を押す | 画面をタップして移動／光の印をタップ、選択肢をタップ |
| 戦闘 | 1〜4キー・コマンド選択（ターン制） | コマンドをタップ |
| 設定 | ヘッダ「設定」で音量・文字・演出・難易度を変更 | 同じ |
| セーブ | 「保存」「続きから」／「記録」→JSON書出し・読み込み | 同じ |

戦闘は味方2行動ごとに敵が動くターン制です。予告・かばう・記憶読解・崩しを組み合わせ、共鳴100で残響を追加行動として使えます。

## セーブ互換性

`web/model.mjs` と `web/save.mjs` のセーブ形式は **version=1** のままです。

- IndexedDB DB: `lumen-veil-save-v1`、object store: `slots`、key: `chapter-zero`。
- 旧版からのブラウザ内保存・JSONインポートに対応。旧セーブの実データ例で回帰テストを実施。
- 別のブラウザ/端末への移行はJSONエクスポート・インポートが必要。ゲーム本体にセーブを外部送信する仕組みはありません。

## Phase 3 — 探索・装備・育成

フィールドはWASD/矢印キー、クリック/タップで歩行。障害物を避ける経路探索に対応し、**Eキー**で近くの地点を調べられます。従来の探索ボタンでも進行可能です。

浮遊港から新たに**白帆の市場**と**星環の観測塔**に寄り道できます。NPCの複数行会話、装備箱の発見、装備・育成画面、経験値とレベル、敵の行動予告を追加しました。

従来のv1セーブと公開URLは変更せず、育成情報は同じIndexedDBの別キーに保存します。JSONエクスポートには育成情報を追加し、旧形式も引き続きインポートできます。詳細は [Phase 3仕様](docs/PHASE3.md) を参照してください。

## Phase 4: 生きた世界

データ駆動タイルマップ（40×20）、巡回NPC、3件の依頼と報酬、白帆の市場の装備店、戦況対応型AI、改善したキャラクター描画を追加。
ゲーム中の「依頼」から受注・報酬受取、「ショップ」は市場で利用可能です。既存のセーブ形式とGitHub Pages URLは変わりません。
詳細は [docs/PHASE4.md](docs/PHASE4.md) を参照してください。


## 戦闘用イラスト

ノエル・セナ・リッツと忘鐘は、独立した透過イラストで表示します。狭い画面でも比率を保ち、手番を足元のリング、戦闘不能を半透明で示します。探索の歩行スプライトとセーブv1は従来のままです。画像を読めなければ既存描画へ戻ります。制作指示と検証方針は [戦闘アート](docs/BATTLE_ART.md) を参照してください。

## アートと品質保証（Issue #17）

市場・観測塔は専用背景、6人のフィールド人物は4方向×4コマの透過WebP、
会話は通常・喜び・不安・驚きの表情画像を使用します。
表情はAVIF→WebP→従来立ち絵、歩行はWebP→SVG→Canvasへフォールバックします。
デザイン基準は [キャラクター仕様](docs/CHARACTER_DESIGNS.md) を参照してください。

`npm test`、`npm run build` の後、`npm run preview` を起動し、
`python tests/e2e.py` で序章・保存再開・タップ操作と
320/390/768/1440pxの全6エリア・会話・戦闘・メニュー画像を検証できます。
PlaywrightとChromiumが必要です。システムChromiumを使う場合は
`CHROMIUM_EXECUTABLE=/usr/bin/chromium` を指定してください。
画像は `screenshots/` に保存されます。

全6章・クラウド同期・リアルタイム敵ATBは今後のゲーム内容拡張です。
音楽は外部音源を必要としないオリジナルのWeb Audio版を継続使用します。

検証内容と#15の判断根拠は [Issue #17 QA](docs/ISSUE17_QA.md) を参照してください。

## 名前を届ける旅への再設計

探索は対象へ近づいた後に「話す・調べる」で実行します。記憶の手帳で痕跡をつなぎ、ミラへの手紙を復元すると忘鐘への道が開けます。探索と戦闘はスマホでも一画面内で操作できる構成です。詳しくは [再設計仕様](docs/JOURNEY_REDESIGN.md) を参照してください。
