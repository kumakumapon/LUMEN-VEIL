# Phase 3 — 自由歩行・会話・敵AI・装備育成・探索拡張

## 実装した範囲

- **自由歩行**：Phaserフィールド上でWASD/矢印キー、クリック・タップ移動。正規化座標の歩行領域、障害物の当たり判定、A*経路探索、Eキーで近くの地点を調べる。目的地リストは従来通り操作でき、アクセシビリティのため残す。
- **NPC**：新エリアの商人ユイ、航路士、星見のエルと、複数行の会話をモーダルで表示。次へ・閉じる・Escapeに対応し、会話中は移動/ATBを停止する。
- **敵AI**：機械兵の規則的な攻撃、忘鐘の残HPによる弱者集中、3回目の敵行動ごとの共鳴鐘撃。次の対象と技を画面に予告。乱数を使わず、再挑戦時も再現可能。
- **装備・育成**：3人それぞれの経験値、Lv.1〜4、武器と防具、攻撃/防御補正。市場の装備箱と観測塔の星図の箱から装備を入手。勝利時に経験値を獲得。装備画面から所持品を装備可能。
- **エリア**：既存の浮遊港・整備回廊・保管庫・船着き場に加え、白帆の市場と星環の観測塔を追加。どちらも港から往復可能な任意の寄り道で、既存序章クリア条件を変更しない。

## セーブ互換性（重要）

- 従来の **v1** セーブ形式と `web/model.mjs` の厳格な `parseSave` を維持。旧フラグ、HP/MP、難易度、共鳴値は従来通り。
- IndexedDB のDB名 `lumen-veil-save-v1`、ストア `slots`、旧キー `chapter-zero` を維持。育成・装備・訪問履歴・宝箱は同じストアの新キー `chapter-zero-expansion` に保存。DBバージョンアップ不要。
- 旧v1 JSONのインポート時は育成情報を初期化して復元。新JSONには任意の `expansion` が付属し、旧v1モデルで読み込んでも未知フィールドとして安全に無視される。
- 拡張JSONのインポートは両部分を**書込み前に検証**し、同じIndexedDBトランザクションで2キーを更新。不正データを取り込んでも既存セーブを破壊しない。
- 旧v1モデルの `snapshot` は新しいフィールドを持たず、従来通りの保存・再開が可能。

## GitHub Pages

Viteの `base: '/LUMEN-VEIL/'` と `dist/`、GitHub ActionsのPagesデプロイワークフローは変更しない。画像は既存の生成済みWebPを市場・観測塔で再利用。音楽は既存のWeb Audioにエリア別のオリジナル短編を追加。

## 受入条件と検証

- `npm test`：旧モデル/互換性テスト、新しい育成・敵AI・探索・歩行メッシュのテスト。
- `npm run build`：TypeScriptの型検査、Vite本番ビルド、Pagesサブパス検証。
- Playwright：序章の通しプレイ、2つの新エリア、NPC会話、装備取得と変更、リロード後の装備復元、モバイル操作。

## 今後の発展

歩行は現在の背景一枚を利用した2.5Dフィールド上の移動で、地形ごとの物理衝突・広域マップ・タイルセット・NPC巡回は次段階。育成上限はLv.4、装備は固定品の収集式。戦闘の難易度や攻撃パターンは今後プレイテストで調整する。
