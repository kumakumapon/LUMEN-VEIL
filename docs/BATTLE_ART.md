# 独立した戦闘用イラスト

生成したノエル・セナ・リッツの全身立ち絵と忘鐘の透過素材を、最新mainのPhaser戦闘画面へ統合する。

## 実装
- `battle-arena.webp` は人物・UIのない専用背景。既存のコンセプト背景に描かれた人物と、可動スプライトが二重にならないよう戦闘中に切り替える。
- `public/assets/battle-{noel,sena,ritz,bell}.webp` を静的配信。公開URLは `/LUMEN-VEIL/` のまま。
- 背景やHUDを含む一枚絵ではなく、敵味方を個別のPhaserスプライトとして描く。
- 縦横比を保ったサイズ計算と足元基準の配置。戦闘不能は半透明、現在の行動者は足元のリングで示す。
- 技の光は現在の行動者から出し、防御の光は本人の位置で完結する。
- 戦闘中は探索用のグリッド・歩行案内を非表示にし、地名は小さなキャプションにして敵味方を遮らない。
- 素材を読めなかったキャラクターは既存の描画へ戻る。通常敵は既存の機械描画を使う。
- 探索用の4コマ歩行、NPC巡回、ゲームモデル、IndexedDB、JSON v1は変更しない。

## 画像制作
組込み画像生成機能で、既存の本企画用世界観絵を参照して人物3人と忘鐘を個別に生成。
生成時に透過背景を指定。配布用にWebPへ縮小・圧縮し、アルファを保持する。
3人を一枚に生成した初期案はスロット間で衣装がはみ出したため採用しない。
採用した人物は静止立ち絵。フルフレームの攻撃・被弾アニメーションは後続。
指示全文は `docs/BATTLE_ART_PROMPTS.json`。生成モデル名を指定する引数はなく、特定のモデル名を保証するものではない。

## 検証
画像寸法・アルファ・Pagesの配置パス、レイアウトの境界値を検証。
既存の進行・戦闘・セーブ互換性テストを維持。
GitHub ActionsのPlaywrightは開発サーバーではなく、Pages用にビルドした成果物をpreviewで起動して通し確認する。
ローカル環境ではChromiumの起動がSIGTRAPで終了するため、ブラウザ結果はCIの実行結果を記録する。
