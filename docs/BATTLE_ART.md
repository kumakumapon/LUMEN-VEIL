# 戦闘用イラストの統合

最新mainのPhaser画面に、生成した3人の全身立ち絵と忘鐘の独立した透過画像を組み込みます。探索の歩行アニメーションとNPC巡回は既存のものを維持します。

- 画像は公開時に同梱し、プレイ中に生成APIは使いません。
- `/LUMEN-VEIL/` の公開パスと、既存のIndexedDB・JSON v1は変更しません。
- 画面幅に合わせて比率を保ち、足元をそろえて表示します。
- 画像読込失敗時は既存の描画に戻ります。
- 主人公の攻撃演出を現在の行動者から出し、戦闘不能の見た目も更新します。
- 既存テスト・ビルド・Pagesパス確認と、GitHub ActionsのPlaywrightで検証します。
